# Parliamo! 旅のイタリア語帳

イタリア旅行のためのフレーズ単語帳とヒアリング練習アプリです。`index.html` をブラウザで開くだけで使えます。

- **単語帳**: 旅行フレーズ105個(9カテゴリ)。カードをめくって意味と読みを確認し、音声で発音を聞けます。覚えたフレーズはブラウザに記録されます。
- **ヒアリング**: 音声を聞いて意味(またはつづり)を4択で答えます。速度は3段階で、間違えたフレーズは出題されやすくなります。

音声はブラウザの読み上げ機能(Web Speech API)を使います。日本語の声で読まれる場合は、端末にイタリア語の音声を追加してください。

GitHub Pages を有効にすると、スマホからURLで開けます(Settings › Pages › Branch: main / root)。
